## Resolved conflicts
- `microcopy.md` lists "Diproses" as a status; the newer rulebook forbids it and uses "Di HR". The package follows the rulebook.
- Focus ring: rulebook says 2px; used 2px.
- Icons: the source rulebook required 49 custom house icons. At the product owner's request the package switched to Lucide only, for a much wider choice. Old names map to Lucide in `EV_ICON_LEGACY`. Some glyphs differ visually, e.g. `alert` is now a circled exclamation point and `activity` is `square-activity`.

## Assumptions
- Gold `#f7c948` estimated from logo pixels.
- Tablet/desktop rules are proposals.
- No font binaries in source → `fonts/` omitted; fonts load from Google Fonts.
