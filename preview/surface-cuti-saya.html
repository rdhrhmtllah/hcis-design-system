Cuti Saya — home

The system assembled: purple header with summary chips, overlapping BalanceCard, shortcuts, active requests with route, recent decisions and the floating nav. Full interactive flow lives in the UI kit.

What to notice
  1. Purple is structure (header, primary key, active nav); gold appears only as small fills — the pill, the button tile, the nav dot.
  2. One big number answers the first question: how many days are left.
  3. Every status is a word plus a dot. "Di HR" shares the waiting orange.
  4. Cards sit on lavender with purple-tinted shadows; no grey borders.
  5. Copy is short, Indonesian, "kamu" voice, verb-first actions.
