Logo Evo Group (rumah emas dengan tulisan EVO GROUP) sebagai PNG berlatar transparan. Dipakai di header aplikasi, halaman masuk, dan materi internal.

- Pakai berkas apa adanya. Jangan mewarnai ulang, memiringkan, atau menggambar ulang.
- Beri ruang bebas minimal setengah tinggi huruf "E" di sekeliling logo.
- Taruh di atas latar terang (`ev-white` atau `ev-bg`). Di atas ungu tua letakkan logo di dalam kartu putih, karena emas tua kurang kontras di atas ungu.
- Ini PNG, bukan SVG, jadi tidak bisa menyesuaikan warna dan kurang tajam di ukuran kecil. Minta berkas vektor resmi dari tim brand untuk ukuran kecil dan untuk menggantikan lambang rumah sederhana pada tombol Menu.
